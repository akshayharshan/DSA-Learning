# Important Graph Concepts Learned

## DFS
- Explore fully before backtracking
- Used for connected components and islands

## BFS
- Level-by-level traversal
- Queue based

## Multi-source BFS
Learned using Rotten Oranges:
- All rotten oranges spread simultaneously
- Each BFS level represents one unit of time
- `for _ in range(len(queue))` freezes the current level size
- Newly appended nodes are processed in next level/minute

---

# Important Tree Concepts Learned

## Symmetric Tree
- Mirror comparison logic
- Compare:
  - left.left ↔ right.right
  - left.right ↔ right.left
- All recursive calls must return True

## Diameter
- Diameter = left_height + right_height
- Use DFS recursion and global tracking

## LCA
- Recursive subtree search
- If both left and right return nodes → current node is LCA
