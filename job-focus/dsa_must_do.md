# DSA Must-Do Problems (Service Company Interviews)

*Focus: Infosys, TCS, Accenture, Cognizant, Wipro*

Goal: Build **muscle memory + confidence** before interviews.

---

# Core Rule

For every problem practice:

1. Write code **without looking**
2. State **Time Complexity**
3. State **Space Complexity**
4. Explain logic **as if in interview**

---

# 1. Foundation Warmups

These should take **<5 minutes each**

* Reverse String
* Count Vowels
* Check Prime Number
* Fibonacci Series
* Palindrome Number
* Sum of Digits (Recursion)
* GCD (Euclidean Algorithm)

---

# 2. HashMap / Array

Very common in service-company interviews.

* Two Sum
* Valid Anagram
* First Non-Repeating Character
* Product of Array Except Self

---

# 3. Sliding Window

Important pattern.

* Longest Substring Without Repeating Characters
* Minimum Size Subarray Sum
* Maximum Sum Subarray of Size K

---

# 4. Prefix Sum

Common trick question.

* Subarray Sum Equals K

---

# 5. Two Pointers

Classic interview problems.

* Container With Most Water
* Trapping Rain Water

---

# 6. Stack

Important pattern.

* Valid Parentheses / Balanced Brackets
* Min Stack
* Largest Rectangle in Histogram

---

# 7. Linked List

Frequently asked.

* Reverse Linked List
* Linked List Cycle
* Linked List Cycle II
* Merge Two Sorted Lists

---

# 8. Heap

Often asked in service companies.

* Kth Largest Element in Array
* Top K Frequent Elements

---

# 9. Sorting Based

Common quick interview problems.

* Sort Colors (Dutch National Flag)
* Merge Intervals

---

# 10. Trees (Very Important)

Most companies ask **1 tree problem**.

* Maximum Depth of Binary Tree
* Diameter of Binary Tree
* Invert Binary Tree
* Level Order Traversal (BFS)

---

# 11. Dynamic Programming (Basic)

Usually one easy DP question.

* Climbing Stairs
* Maximum Subarray (Kadane's Algorithm)

---

# Total Core Problems

≈ **30 problems**

This set covers **80-90% of questions** asked in service-company interviews.

---

# Daily Revision Strategy

Daily practice:

* 5 problems/day
* 2 easy
* 2 medium
* 1 revision

Focus on **writing code from memory**.

---

# Interview Mindset

In interview always say:

1. Brute force idea
2. Optimized approach
3. Complexity
4. Edge cases

Even if code is not perfect, **clear thinking impresses interviewers**.

---

# Final Advice

You do NOT need 200 LeetCode problems.

Master these **30 problems deeply** and you will be ready for most service-company interviews.
